美术课互动选择流程图

【第一节课】

• 触发：画面不太满意

◦ 选1：随便交了 → 【A-】
◦ 选2：回去找资料努力画到最好 → 作业及时上交/晚交/期末补交/忘记交
选3：求助老师，修改满意→作业及时上交/晚交/期末补交/忘记交

【第二节课】

• 触发：和同学争执

◦ 选1：课后解决，回到课堂活动 → 作业及时上交/晚交/期末补交/忘记交

◦ 选2：事情严重 ，必须打断课堂→ 【纪律分-1且打扰到其他同学创作自己也无法高效完成作品】→作业及时上交/晚交/期末补交/忘记交

【第三节课】

• 触发：作品被意外损坏或者一笔画"毁了"。

◦ 选1： 生气，别无他法→ 作业及时上交/晚交/期末补交/忘记交

◦ 选1：巧妙利用，弄拙成巧 → 作业及时上交/晚交/期末补交/忘记交

◦ 选2：重画，画得非常完美→ 【需要自己课外找时间，可能影响其他科目作业完成，创作时间紧张】→作业及时上交/晚交/期末补交/忘记交

【第四节课】

• 触发：老师下发的创作材料丢失

◦ 选1：放弃创作→ 无作业
◦ 选2：自己在生活中寻找类似材料，作品反而更有新意→及时上交/晚交/期末补交/忘记交
◦ 选3：课前找老师及时补充材料。 →及时上交/晚交/期末补交/忘记交

结算规则：只要交作业每节课会得到一个等地，A+加一分，违反纪律扣一分，每次得到A以下等地会触发加分机会，1问老师，修改画面，直到得A，2这个画法不太擅长，或者不感兴趣，以后的课堂积极参与获得加分，3等待后面其他作业机会得到A+(不确定)，4放弃加分。可以选择把握或者放弃。最终累计全A不扣分就通关。
每次交作业机制，根据不同情况随机给出成绩，有些情况不可能A，有些大概率A+。这个要可以手动调
只要到A以下触发加分机制
